#P and #3SAT

Definition 2.1 #P

A function f:{0,1}*→ℤ≥0f:\{0,1\}^*\to\mathbb Z_{\ge 0} belongs to #P\#\mathrm{P} if there exist a nondeterministic Turing machine MM and a polynomial pp such that, for every input xx, each computation path of MM halts within p(|x|)p(|x|) steps and exactly f(x)f(x) of those paths accept.

Equivalently, ff counts witnesses. There is a polynomial qq and a deterministic polynomial-time verifier VV such that

f(x)=|{w∈{0,1}q(|x|):V(x,w)=1}|.f(x)=\bigl|\{w\in\{0,1\}^{q(|x|)} : V(x,w)=1\}\bigr|.

Starting from the verifier, we construct a nondeterministic machine by branching on each of the q(|x|)q(|x|) bits of ww. This gives us one leaf for each possible witness. At the leaf labeled ww, we run V(x,w)V(x,w) and accept precisely when the verifier does. Hence we count exactly f(x)f(x) accepting paths.

Conversely, suppose we start with a machine that makes binary nondeterministic choices. Its polynomial time bound limits how many choices we have to record on any path. For our witness length we use that bound, reading one bit each time the machine makes a choice. When the path ends, we require every unused bit to be zero. For example, an accepting path with five choices has only one valid witness, the five bits we read followed by zeros. Thus we count each accepting path just once.

Definition 2.2 #3SAT

A 3-CNF formula φ\varphi on nn Boolean variables is a conjunction of clauses, each a disjunction of at most three literals. A literal is a variable or its negation. The number of satisfying assignments is

#3SAT(φ)=|{a∈{0,1}n∣φ(a)=1}|.\#\mathrm{3SAT}(\varphi) =\bigl|\{a\in\{0,1\}^n\mid\varphi(a)=1\}\bigr|.

On a 3-CNF input, #SAT(φ)\#\mathrm{SAT}(\varphi) denotes the same count.

For #3SAT\#\mathrm{3SAT}, we take as our witness an assignment to the nn variables. We check each clause and accept the witness if it satisfies all of them. Thus we obtain exactly one accepting witness for each satisfying assignment, proving that #3SAT\#\mathrm{3SAT} belongs to #P\#\mathrm P.

We first use the permanent algorithm to count assignments to formulas with O(n)O(n) clauses. To use that bound on an arbitrary formula φ\varphi, we would like to express its count as a sum of counts for sparse formulas. For the sum to be correct, each satisfying assignment of φ\varphi must satisfy exactly one of the formulas in the sum.

Lemma 2.3 Counting sparsification

For every fixed η>0\eta>0, an nn-variable 3-CNF φ\varphi can be split in 2ηnpoly⁡(|φ|)2^{\eta n}\operatorname{poly}(|\varphi|) time into at most 2ηn2^{\eta n} 3-CNFs on the same variables, each with at most CηnC_\eta n clauses. Their satisfying assignments partition those of φ\varphi. In particular, the sparse bound of Theorem 1.1 yields a counting algorithm for arbitrary 3-CNFs in time 2δnpoly⁡(|φ|)2^{\delta n}\operatorname{poly}(|\varphi|) for every fixed δ>0\delta>0.

To obtain the running time in the last assertion, we fix δ>0\delta>0 and set η=δ/2\eta=\delta/2. The matrix associated with each sparse formula has at most (1+7Cη)n(1+7C_\eta)n rows. Since CηC_\eta is now a constant, the time to compute its permanent is 2o(n)2^{o(n)}. In particular, for sufficiently large nn we can count the assignments of one such formula in 2δn/22^{\delta n/2} time up to polynomial factors. There are at most 2δn/22^{\delta n/2} formulas. Therefore we can compute and add their counts in 2δnpoly⁡(|φ|)2^{\delta n}\operatorname{poly}(|\varphi|) time. To decide satisfiability, we test whether the sum is positive.

Counting and decision complexity

A count of one and a count of seventeen give the same answer to the decision problem 33-SAT. In either case a satisfying assignment exists. For any polynomial-time verifier, we define a function in #P\#\mathrm P by counting its accepting witnesses. To decide membership in the associated NP\mathrm{NP} language, we accept precisely when this count is positive. In other words, L∈NPL\in\mathrm{NP} if and only if there is some f∈#Pf\in\#\mathrm P such that

x∈L⇔f(x)>0.x\in L \quad\Longleftrightarrow\quad f(x)>0.

To state a containment between decision classes, we give a deterministic polynomial-time machine an oracle for a counting function. On a query xx the oracle returns the integer f(x)f(x), which the machine can use in the rest of its computation. If we allow any f∈#Pf\in\#\mathrm P as the oracle, we obtain the class P#P\mathrm P^{\#\mathrm P}. In fact, an oracle for #3SAT\#\mathrm{3SAT} alone suffices.

For the reduction, we fix an input xx to a verifier VV. We construct a polynomial-size circuit that computes V(x,w)V(x,w) on input ww and introduce a variable for the output of each gate. For instance, suppose we have an AND gate with inputs u,vu,v and output zz. The clauses (¬z∨u)(\neg z\vee u) and (¬z∨v)(\neg z\vee v) say that if z=1z=1, both inputs must be 11. The clause (z∨¬u∨¬v)(z\vee\neg u\vee\neg v) gives the converse. Together they express z=u∧vz=u\wedge v. For OR and NOT gates we can likewise use clauses of width at most three.

At every gate we impose these constraints, and at the output we require the value 11. All witness bits must appear among the variables of the formula. If the circuit ignores a bit wjw_j, we include it by adding the clause wj∨¬wjw_j\vee\neg w_j. Once we fix the witness bits, we determine every gate variable by evaluating the gates in order. An accepting witness has exactly one satisfying extension, and a rejected witness has none. Hence we obtain f(x)f(x) with one query to #3SAT\#\mathrm{3SAT}.

The following inclusions relate the resulting decision class to NP\mathrm{NP}, the polynomial hierarchy, and PSPACE\mathrm{PSPACE}.

P⊆NP⊆PH⊆P#P⊆PSPACE.\mathrm P\subseteq\mathrm{NP}\subseteq\mathrm{PH} \subseteq\mathrm P^{\#\mathrm P}\subseteq\mathrm{PSPACE}.

For example, we can describe a language at the second existential level of PH\mathrm{PH} by ∃u∀vR(x,u,v)\exists u\,\forall v\,R(x,u,v), where the lengths of u,vu,v are polynomially bounded and RR is decidable in polynomial time. At higher levels the number of alternating quantifier blocks may increase, but it remains a constant for any fixed level. By Toda’s theorem, we can decide every language in this hierarchy in polynomial time given a #P\#\mathrm P oracle.

For the final inclusion, suppose the machine asks an oracle query whose witnesses have length mm. We enumerate the 2m2^m witnesses, run the verifier on each one, and count those it accepts. We need m+1m+1 bits for the counter, and we can reuse the space for checking one witness when we move to the next. Since the original machine runs in polynomial time, its query lengths are polynomially bounded, as are the corresponding witness lengths. Hence we can simulate the entire computation in polynomial space.
