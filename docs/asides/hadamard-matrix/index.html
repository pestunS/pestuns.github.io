Hadamard matrix

Definition 5.1 Hadamard matrix

A real Hadamard matrix of order NN is a matrix H∈{−1,1}N×NH\in\{-1,1\}^{N\times N} satisfying HH𝖳=NINHH^{\mathsf T}=N I_N, where INI_N is the identity matrix. Each row has squared length NN, so the identity holds exactly when distinct rows are orthogonal.

For N=2ℓN=2^\ell we can construct a Hadamard matrix by labeling its rows and columns with bit strings from {0,1}ℓ\{0,1\}^\ell, in binary order. For row uu and column vv, we take their dot product u⋅vu\cdot v modulo two and set Hu,v=(−1)u⋅vH_{u,v}=(-1)^{u\cdot v}. To determine the sign, we count the positions at which both strings have a 11 and take the parity of that count. For instance, in row 101101 the entry is +1+1 if the first and last bits of the column agree, and −1-1 if they differ. The resulting matrices are called the Walsh–Hadamard matrices.

To construct H2NH_{2N} from HNH_N, we add a leading bit aa to the row label uu and a leading bit bb to the column label vv. Their dot product becomes ab+u⋅vab+u\cdot v modulo two. Thus we change the sign only when a=b=1a=b=1, which in binary order is the lower-right block. This gives us Sylvester’s recursive construction

H1=(1),H_1=(1),
H2N=(HNHNHN−HN).H_{2N}=\begin{pmatrix}H_N&H_N\\H_N&-H_N\end{pmatrix}.

Starting from H1=(1)H_1=(1), we first obtain the two rows (1,1)(1,1) and (1,−1)(1,-1). At each further step we double the number of rows and columns.

To check that the rows are orthogonal, we fix distinct row labels uu and ww and choose a position jj where they differ. We pair each column vv with the column v′v' obtained by changing bit jj. Of the two rows, exactly one has a 11 in its label at position jj. Its entry changes sign between vv and v′v', while the entry in the other row stays the same. Hence we get two contributions to the inner product that cancel. Since we have paired every column exactly once, the full inner product is zero.

Since u⋅v=v⋅uu\cdot v=v\cdot u, we also have HN𝖳=HNH_N^{\mathsf T}=H_N. Thus HN2=NINH_N^2=NI_N for N=2ℓN=2^\ell. If we apply HNH_N twice to a vector, we multiply it by NN. Hence we have HN−1=N−1HNH_N^{-1}=N^{-1}H_N.
